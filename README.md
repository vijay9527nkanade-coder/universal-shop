# FastAPI + Flutter Project

A full-stack starter with a **Python FastAPI** backend and a **Flutter** mobile app.

## Repository Structure

```
fastapi_flutter_project/
├── backend/          # Python FastAPI + SQLAlchemy + PostgreSQL
└── app/              # Flutter application (Android & iOS)
```

See each folder's own `README.md` for setup instructions.

## Prerequisites

| Tool         | Version |
|--------------|---------|
| Python       | 3.11+   |
| Flutter      | 3.38+   |
| PostgreSQL   | 14+     |

## Development Workflow

1. Start the backend (see `backend/README.md`)
2. Run the Flutter app: `cd app && flutter run`
